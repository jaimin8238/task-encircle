CedarMillCo — ACF Pro Field Guide

No manual field creation is needed. Both field groups register automatically from the theme. Homepage sections appear inside Pages → Home. Shared settings appear under Header & Footer. Requires ACF Pro.

Group 1: Cedar Mill — Homepage Sections. Location: Post Type = Page. Main field: Flexible Content / Homepage Sections / cm_homepage_sections.

Group 2: Cedar Mill — Header & Footer Options. Location: Options Page = cedarmillco-options.

Defaults below are the exact ACF settings. Most start blank. The optional Load Reference Content button fills your chosen page with the reference text, original images and repeater rows. Reference values are listed in REFERENCE-CONTENT.md. No default image IDs can be shared across separate WordPress installations.
