CedarMillCo 2.0 — Start Here

This is the ACF Pro version. All homepage sections live inside Pages → Home. The shared Header & Footer menu uses genuine ACF Options. ACF Pro itself is supplied separately.
  1. Copy the extracted CedarMillCo folder into your existing wp-content/themes/ folder, replacing the earlier theme files.
  2. Activate the ACF Pro plugin supplied to you, then activate the CedarMillCo theme.
  3. Open Pages → Home → Edit. Above the editor, click Load Reference Content Into This Page. If you edited version 1 content, choose Migrate Version 1 Content Into This Page instead. Existing populated sections are not overwritten.
  4. Find Homepage Sections. The eight layouts appear one by one: Hero, Intro Statement, Product Categories, Every Detail, Featured Project, CTA Band, Newsletter and Instagram Grid.
  5. Expand a row to edit its text, image, nested cards/buttons and Section — Optional Colors. Drag, duplicate, remove or add rows using ACF controls. Click Update.
  6. Open Header & Footer for logos, top-bar text, shared content, CTA buttons, offices, social links and colors.
  7. Your selected Primary Menu is preserved. Confirm its assignment under Appearance → Menus. Indent Products/Projects children one level to create dropdowns.
  8. If needed, choose Home under Settings → Reading → Homepage. Setup does not replace this assignment.
